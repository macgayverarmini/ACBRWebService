# ACBr Component Suite

**ACBr** (Automação Comercial Brasil) is an open-source Pascal component library for electronic tax invoicing (NFe, CTe, MDFe, NFSe), fiscal printing (ESCPOS), SAT, and commercial automation in Brazil.

- **Role in ACBRWebService**: Core engine for tax document validation, XML processing, webservice communication with SEFAZ, and hardware printing.
- **Repository**: [Projeto ACBr](https://www.projetoacbr.com.br/)
