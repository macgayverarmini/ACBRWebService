# Horse Framework

**Horse** is a minimalist web framework for Delphi and Free Pascal (Lazarus), inspired by Express.js.

- **Role in ACBRWebService**: Acts as the primary HTTP server and router.
- **Middleware**: Integrated with `jhonson` for automatic JSON request parsing and `handle-exception` for structured error handling.
- **Repository**: [HashLoad/horse](https://github.com/HashLoad/horse)
