# Summary: Tools & Utility Scripts

Details helper units and automation tooling:
- **`TJSONTools` (`jsonconvert.pas`)**: Lazarus FPC RTTI reflection engine mapping JSON objects to Pascal instances.
- **`generate_swagger.py` & `update_postman.py`**: Automated API documentation and Postman collection generators.
- **`compile_resources.py`**: Binary resource compilation utility.
