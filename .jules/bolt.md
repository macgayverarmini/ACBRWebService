## 2025-06-04 - Avoid redundant inline function calls and TBytes allocations in stream conversions
**Learning:** In Lazarus/FPC, passing an inline function call to `WriteBuffer` multiple times (e.g., `WriteBuffer(Func()[1], Length(Func()))`) results in redundant and expensive evaluation. Additionally, converting between `TBytes` arrays via `TEncoding.UTF8.GetString` and `TEncoding.UTF8.GetBytes` when reading/writing from streams is slower and consumes more memory than using native strings with `ReadBuffer` and `WriteBuffer`.
**Action:** When manipulating streams, prefer using `ReadBuffer` and `WriteBuffer` directly with native strings (e.g., `AStream.ReadBuffer(str[1], AStream.Size)`), and pre-compute expensive function calls into local variables if their result is used multiple times.
