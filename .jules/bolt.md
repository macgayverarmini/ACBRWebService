## 2024-05-18 - Reduce Object Allocation Overhead in Recursive JSON Serialization/Deserialization
**Learning:** `TRttiContext` creation (`TRttiContext.Create(False)`) in Pascal/Delphi is an expensive operation due to internal structure caching and memory allocation. The recursive methods `InternalObjToJson` and `JsonToObj` inside `tools/jsonconvert.pas` were previously recreating `TRttiContext` on every single nested object or collection item processing loop, causing severe O(N) performance degradation during (de)serialization of large JSON payloads.
**Action:** Extract expensive context object instantiations to public method entry points (e.g., `ObjToJson`, `JsonToObj`) and propagate a shared `TRttiContext` instance as a parameter through internal recursive procedures like `InternalObjToJson` and the new `InternalJsonToObj` to reuse allocations and minimize overhead drastically.
