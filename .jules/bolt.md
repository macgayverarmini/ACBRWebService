## 2024-05-24 - Avoid TBytes allocation and Redundant Function Calls in Stream Operations
**Learning:** In Free Pascal, allocating intermediate `TBytes` arrays and converting them to strings via `TEncoding.UTF8.GetString` and `TEncoding.UTF8.GetBytes` when interacting with Streams (like `TMemoryStream`) adds unnecessary overhead. Furthermore, executing the same inline function call (e.g. `base64.EncodeStringBase64`) twice as arguments to a procedure like `WriteBuffer(Func()[1], Length(Func()))` causes redundant and potentially expensive evaluations.
**Action:** When dealing with streams and strings, interact natively with the stream buffer using `AStream.ReadBuffer(Str[1], Size)` and `AStream.WriteBuffer(Str[1], Length)`. Also, always cache the results of expensive computations in local variables rather than re-evaluating them inline as arguments.
