## 2025-02-27 - Stream Encoding Optimization in Pascal
**Learning:** Redundant evaluation of functions within inline parameters (e.g., `Result.WriteBuffer(EncodeString(S)[1], Length(EncodeString(S)))`) causes inefficient performance in Pascal. Additionally, bridging Stream data and Base64 string generation via intermediate `TBytes` buffer allocation and `TEncoding.UTF8` operations creates measurable memory overhead when direct string sizing and stream operations can avoid it entirely.
**Action:** Store the result of expensive computations (like base64 encoding) in a local variable before passing it to subsequent procedures or parameters. Eliminate `TBytes` intermediation by directly utilizing native string types with `SetLength` when reading from or writing to `TMemoryStream` buffers for performance and memory optimization. Ensure guard checks (e.g., `if Length(S) > 0`) are present to prevent index out of bounds exceptions on native string indexing operations.
