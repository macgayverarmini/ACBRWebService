## 2026-05-17 - Avoid String-to-Bytes Roundtrips and Redundant Function Calls in Stream Operations
**Learning:** In Free Pascal/Delphi, repeatedly converting strings to `TBytes` via `TEncoding.UTF8.GetBytes` and back via `GetString` before encoding/decoding Base64 adds unnecessary memory allocation overhead. Additionally, passing the result of an inline function like `EncodeStringBase64` multiple times as arguments to a method (e.g., `Result.WriteBuffer(Func()[1], Length(Func()))`) causes the compiler to evaluate the expensive function redundantly.
**Action:** Always read/write directly from streams to native string buffers using `SetLength` and `ReadBuffer/WriteBuffer`. Cache the result of expensive computations in a local variable before using it multiple times in a function call.
