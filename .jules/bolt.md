## 2024-05-30 - Optimize Stream Reading and Write Buffer Redundancy in Free Pascal
**Learning:** In Free Pascal/Lazarus, allocating a `TBytes` dynamic array and using `TEncoding.UTF8.GetString` to read from a `TMemoryStream` creates unnecessary overhead and memory allocations. It is much more efficient to use native strings directly by pre-allocating the string length and passing the first character's address to `TStream.ReadBuffer`. Furthermore, passing the same inline function call multiple times as arguments to a procedure (e.g., `WriteBuffer(Func()[1], Length(Func()))`) causes the compiler to evaluate the function redundantly.
**Action:** When dealing with streams in Pascal, prefer `TStream.ReadBuffer` and `WriteBuffer` with native strings (e.g., `ReadBuffer(Str[1], Size)`) instead of `TBytes` when reading/writing string data. Always store the result of expensive computations in a local variable before using it multiple times in a procedure call to prevent redundant executions.
