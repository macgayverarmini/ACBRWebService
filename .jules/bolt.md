## 2024-06-22 - Optimize TMemoryStream to String Base64 Conversion
**Learning:** In Free Pascal/Lazarus, allocating intermediate `TBytes` arrays via `TEncoding.UTF8.GetBytes` and `GetString` when reading from or writing to `TMemoryStream` creates unnecessary memory overhead. Furthermore, passing an inline function call like `base64.EncodeStringBase64()` multiple times as arguments to `WriteBuffer(Func()[1], Length(Func()))` causes redundant evaluation of the expensive function.
**Action:** When dealing with string and stream conversions, directly manipulate the string buffer using `ReadBuffer(Str[1], Size)` or `WriteBuffer(Str[1], Size)`, ensuring the stream size is > 0. Cache expensive inline function calls (like string encoding) in a local variable before passing them to `WriteBuffer` to prevent duplicate evaluation.
