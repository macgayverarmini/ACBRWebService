## 2024-05-24 - Avoid TBytes intermediate arrays and redundant inline function calls for stream operations
**Learning:** In Lazarus/FPC, using `TEncoding.UTF8.GetBytes` to create intermediate `TBytes` arrays before reading from or writing to `TMemoryStream` introduces unnecessary memory allocations and conversion overhead. Furthermore, passing an inline function call like `base64.EncodeStringBase64` to both the buffer and length arguments of `WriteBuffer` causes the compiler to evaluate the expensive function redundantly.
**Action:** Use native string types directly with `AStream.ReadBuffer(str[1], AStream.Size)` and `AStream.WriteBuffer(str[1], Length(str))` (after checking for non-empty lengths). Always cache the result of expensive computations in a local variable before passing it to multiple arguments.
