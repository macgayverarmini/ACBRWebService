## 2024-05-24 - Optimize Base64 Stream Operations
**Learning:** In Lazarus/FPC, interacting with streams via intermediate `TBytes` arrays created through `TEncoding.UTF8.GetBytes/GetString` introduces unnecessary memory allocations and conversion overhead. Furthermore, passing an inline function call to `WriteBuffer` (e.g., `WriteBuffer(Func()[1], Length(Func()))`) causes the compiler to evaluate the function redundantly.
**Action:** Use native string types directly with `TMemoryStream.ReadBuffer` and `WriteBuffer` (e.g., `SetLength(str, Size); AStream.ReadBuffer(str[1], Size)`). Always check that the string length is greater than 0 before attempting 1-based indexing (`str[1]`). Cache the result of expensive computations in a local variable before passing it to procedures like `WriteBuffer` to avoid redundant evaluations.
