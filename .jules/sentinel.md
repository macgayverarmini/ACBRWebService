## 2024-05-18 - Hardcoded File Paths & Global State in Route Handlers
**Vulnerability:** A global `TextFile` variable and hardcoded logging paths (`C:\NFMonitor\src\bin\log_debug.txt`) in `routes/route.acbr.nfe.pas` exposed local directory structures, caused path resolution errors on Linux/Docker deployments, and created a race condition / DoS vector during concurrent requests because multiple threads would try to manipulate the same global file descriptor.
**Learning:** Route handlers must remain stateless. Legacy debug blocks wrapped in `try..except` hide potential I/O crashes and should not be deployed in production. Hardcoded Windows paths are incompatible across platforms and can leak server environment details.
**Prevention:** Avoid globally declaring mutable state like file descriptors in Pascal web route units. Ensure any required logging relies on configured, abstract paths (e.g., using `RSDefaultCertPath` equivalents or centralized logging frameworks) rather than inline, hardcoded `AssignFile` / `Append` logic. Remove `try..except` blocks that simply swallow errors meant for developers.
