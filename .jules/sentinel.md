## 2025-02-26 - Removed legacy debug blocks exposing hardcoded paths and risking DoS
**Vulnerability:** Found legacy debug logging blocks in `routes/route.acbr.nfe.pas` writing directly to a hardcoded path (`C:\NFMonitor\src\bin\log_debug.txt`) using a globally declared file descriptor (`var F: TextFile;`). This risks exposing underlying server directory structures (path exposure) and introduces concurrency issues since the file descriptor was global, opening up vectors for Denial of Service if multiple requests attempted to write simultaneously.
**Learning:** Legacy debugging constructs left in production code not only leak internal system layout but also introduce thread-safety issues when global state (like a global file variable in a web framework handling concurrent requests) is used.
**Prevention:** Remove debugging blocks from production API routes, especially those with hardcoded system paths, and never declare stateful resources (such as file handles or database connections) as global variables in route handlers to avoid concurrency-related DoS vulnerabilities.
