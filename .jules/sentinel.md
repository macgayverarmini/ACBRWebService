## 2025-02-23 - Prevented DoS and Information Disclosure from Global File Logging
**Vulnerability:** A global file descriptor (`var F: TextFile;`) was used in asynchronous HTTP server route context (`routes/route.acbr.nfe.pas`) pointing to a hardcoded path (`'C:\NFMonitor\src\bin\log_debug.txt'`).
**Learning:** Using global mutable file descriptors in asynchronous or threaded HTTP frameworks (like Horse) creates severe race conditions under concurrent requests. In extreme cases, concurrent requests attempting to open and append to the same file descriptor can cause server crashes, locks, or partial Denial of Service. Additionally, the hardcoded path disclosed the internal directory structure (`C:\NFMonitor\...`) unnecessarily.
**Prevention:** Avoid declaring `TextFile` or using `AssignFile`/`Append` in route handlers for debugging, especially using globally declared variables. Use safe, concurrency-aware logging mechanisms if debugging is required, and avoid hardcoding internal server paths in source code.
