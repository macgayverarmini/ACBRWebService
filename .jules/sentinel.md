## 2024-06-05 - DoS and Path Traversal Risks from Legacy Debug Logging in Concurrent HTTP Routes
**Vulnerability:** A global `TextFile` descriptor (`var F: TextFile;`) was declared in the implementation section of web routes (e.g., `routes/route.acbr.nfe.pas`) alongside legacy `try..except` debug logging blocks writing to a hardcoded Windows path (`C:\NFMonitor\src\bin\log_debug.txt`).
**Learning:** Using global variables for file descriptors in a concurrent web framework (Horse/Lazarus) introduces significant concurrency/DoS vulnerabilities since multiple requests modify the same descriptor simultaneously. Furthermore, using hardcoded absolute file paths can lead to path traversal/file overwrite vulnerabilities and information disclosure on production environments.
**Prevention:** Never use global variables for IO operations in web route units. Ensure any required logging uses a thread-safe, concurrent logging mechanism. Remove or replace hardcoded legacy paths with configurable environment variables (like `RSDefaultCertPath`).
