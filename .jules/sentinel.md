## 2024-05-18 - Path Disclosure and Concurrency Risk in Legacy Debug Code
**Vulnerability:** A global file descriptor (`var F: TextFile;`) was used in conjunction with legacy debug logging that wrote to a hardcoded absolute Windows path (`C:\NFMonitor\src\bin\log_debug.txt`) within a concurrent web route handler (`PostNFe`).
**Learning:** Using global state for file I/O in web route handlers creates severe concurrency issues, potentially leading to a Denial of Service (DoS) due to file locking conflicts. Furthermore, hardcoded absolute paths leak internal system structure (Path Disclosure) and can fail or be manipulated in different deployment environments.
**Prevention:** Avoid using global variables for file handles or state in route implementations. If logging is necessary, use a thread-safe, dedicated logging framework with configurable paths via environment variables or constants (like `RSDefaultCertPath`), and never commit debug artifacts pointing to specific local machine paths.
