## 2024-05-18 - Global File Descriptor and Hardcoded Debug Paths
**Vulnerability:** The web route implementation in `routes/route.acbr.nfe.pas` declared a global `var F: TextFile;` and used it to write to a hardcoded debug path (`C:\NFMonitor\src\bin\log_debug.txt`). This setup introduces a Denial of Service (DoS) and race condition vulnerability when handling concurrent requests, as multiple threads attempt to access the same global file descriptor simultaneously.
**Learning:** In a concurrent web framework context (like Horse), declaring global variables for per-request operations like file logging is unsafe. Legacy debug blocks wrapped in `try..except` hide potential I/O errors and can silently cause crashes or unexpected behaviors.
**Prevention:** Avoid global variables for request-scoped I/O. Use proper logging frameworks or dynamically configured, request-isolated file descriptors. Ensure hardcoded debug paths are removed and replaced with configurable paths to prevent unexpected file access behaviors and path traversal/permissions issues.
