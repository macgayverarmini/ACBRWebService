## 2024-05-19 - Removed Hardcoded Paths and Global File Descriptors
**Vulnerability:** The code contained hardcoded paths to a debug log file (`C:\NFMonitor\src\bin\log_debug.txt`) and a global `TextFile` descriptor (`var F: TextFile;`) in `routes/route.acbr.nfe.pas`, causing potential path traversal, disclosure of the directory structure on the underlying system, and a potential DoS vulnerability or silent logging failures due to concurrency issues with the global file descriptor.
**Learning:** Hardcoded absolute paths limit portability and can expose details of the host's file system layout. Furthermore, in web route implementations (e.g., using the Horse framework), declaring file descriptors globally creates concurrency issues and potential DoS risks during concurrent requests as well as information leakage or corrupted logs.
**Prevention:** Avoid declaring file descriptors globally in web route implementations. Always use localized variable scopes. Remove legacy debugging blocks that write to hardcoded absolute paths, especially when deploying in different environments. Use configurable paths when needed.
