## 2024-05-24 - Path disclosure and concurrency DoS risk in web routes
**Vulnerability:** Global variables (e.g. `var F: TextFile;`) in web route implementations and hardcoded logging paths (`C:\NFMonitor\src\bin\log_debug.txt`).
**Learning:** Hardcoded file paths and `TextFile` descriptors declared at the global unit level are not thread-safe. During concurrent web requests, multiple threads will attempt to open and write to the same file descriptor, leading to I/O exceptions, crashes, and a potential Denial of Service (DoS). Additionally, hardcoding paths in standard locations (like `C:\...`) unnecessarily exposes sensitive environment structures in stack traces or logs, and allows arbitrary path disclosure if not properly checked.
**Prevention:** Remove global file descriptors and hardcoded paths in web frameworks like Horse. If logging is needed, use properly scoped (local) and synchronized logging mechanisms, and rely on secure global configuration variables (like `RSDefaultCertPath`) instead of hardcoded strings.
