## 2024-05-24 - Concurrency and Information Disclosure Vulnerability in Web Routes
**Vulnerability:** A global file descriptor (`var F: TextFile;`) was declared in `routes/route.acbr.nfe.pas` and used within the `PostNFe` route handler to append logs to a hardcoded Windows path (`C:\NFMonitor\src\bin\log_debug.txt`).
**Learning:** Using global file descriptors in multi-threaded environments or web route handlers causes severe concurrency issues (race conditions, file locking errors, DoS risks) when multiple requests hit the route simultaneously. Additionally, hardcoded file paths (like `C:\NFMonitor\...`) leak internal system topology, presenting a sensitive information disclosure risk, and will fail on Unix-like systems, causing unhandled or hidden exceptions (which were previously swallowed by empty `except end;` blocks).
**Prevention:** Never use global variables for file manipulation in route handlers. Use dedicated, thread-safe logging mechanisms (e.g., standard output, a robust logging library, or configurable application-level loggers) and always use environment variables or dynamic paths instead of hardcoding absolute file paths.
