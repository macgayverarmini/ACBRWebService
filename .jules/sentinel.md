## 2024-05-13 - [HIGH] Fix race condition and hardcoded path in NFe route
**Vulnerability:** A global file descriptor (`var F: TextFile;`) was declared in `routes/route.acbr.nfe.pas` and used concurrently inside the HTTP POST route `PostNFe` to log debug output to a hardcoded path `C:\NFMonitor\src\bin\log_debug.txt`. This creates a severe race condition during concurrent HTTP requests leading to application crashes or denial of service, while also leaking sensitive file path structures.
**Learning:** Using global variables for I/O operations inside route handlers breaks the concurrency model of the web framework (Horse), and hardcoded absolute debug paths expose the application to DoS and path traversal risks. Legacy debugging blocks inside `try..except end;` silently swallow the concurrent access errors.
**Prevention:** Avoid declaring stateful global variables (like file descriptors) in route units. If logging is required, use thread-safe logging mechanisms configured via centralized, configurable paths, not hardcoded string literals. Never use silent catch-all exception blocks for I/O.
