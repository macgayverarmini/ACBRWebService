## 2025-03-01 - Fix Hardcoded Debug Logging Path & Global TextFile Descriptor
**Vulnerability:** Path Traversal / Information Disclosure (exposing hardcoded file paths like `C:\NFMonitor\src\bin\log_debug.txt`), and potential DoS / Concurrency issue caused by a globally shared `var F: TextFile;` being accessed concurrently in web route handlers.
**Learning:** Legacy debug logging blocks in Pascal source files, especially those writing to fixed paths via a global file descriptor, can lead to both severe security and concurrency flaws. If multiple web requests access `PostNFe` concurrently, they try to manipulate the same global `F` variable, causing runtime exceptions or DoS. Additionally, hardcoded file paths give insight into the host directory structure.
**Prevention:** Avoid legacy file descriptors (like `AssignFile`) and never use global variables for file manipulation in a concurrent context (like Horse web routes). Log to standardized output or specific localized loggers, and remove unnecessary internal path exposures.
