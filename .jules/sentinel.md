## 2024-05-18 - Global File Descriptor Concurrency and Information Disclosure Vulnerability
**Vulnerability:** A global `var F: TextFile;` was used in `routes/route.acbr.nfe.pas` along with hardcoded legacy debugging file paths (`C:\NFMonitor\src\bin\log_debug.txt`). This created a high risk of concurrency issues (race conditions where multiple requests write to the same file descriptor simultaneously), leading to application crashes, potential Denial of Service (DoS), and information disclosure via exposed sensitive logs on hardcoded paths.
**Learning:** In a multi-threaded web environment (like the Horse framework), global file descriptors must never be used to log request data due to thread-safety issues. Hardcoded file paths (`C:\...`) also create an attack vector and potential directory traversal issues.
**Prevention:** Avoid declaring file descriptors globally in web route implementations. Remove legacy debug/logging logic using `AssignFile` to hardcoded paths. Ensure proper dependency injection and logging frameworks are used.
