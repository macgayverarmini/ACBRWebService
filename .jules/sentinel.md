## 2024-05-31 - Fix Global File Descriptor and Hardcoded Debug Path
**Vulnerability:** The `routes/route.acbr.nfe.pas` file contained a global file descriptor (`var F: TextFile;`) and hardcoded Windows paths (`C:\NFMonitor\src\bin\log_debug.txt`) for legacy debugging in a Horse framework web route.
**Learning:** Global variables in a concurrent web framework context (like Horse) can lead to race conditions or denial of service when multiple requests attempt to open or write to the same file descriptor simultaneously. Hardcoded paths to debug files also pose a risk of path traversal or sensitive information disclosure, especially when wrapped in overly broad `try...except` blocks that silently ignore I/O errors.
**Prevention:** Avoid using global file descriptors in route handlers. Remove legacy debug blocks and avoid hardcoding absolute paths. Use appropriate logging mechanisms, scoped variables, and configurable paths (like `RSDefaultCertPath` for certificates) when file operations are genuinely necessary.
