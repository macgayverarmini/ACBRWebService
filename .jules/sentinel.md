## 2024-06-14 - Remove legacy debug file writes and global TextFile descriptor in routes
**Vulnerability:** A global file descriptor (`var F: TextFile;`) was declared and used along with hardcoded debug file paths (`C:\NFMonitor\src\bin\log_debug.txt`) inside the `PostNFe` web route in `routes/route.acbr.nfe.pas`.
**Learning:** Using global file descriptors in web frameworks like Horse creates race conditions and concurrency issues leading to DoS during simultaneous requests. Additionally, hardcoded file paths expose sensitive directory structure details (path leakage) and can lead to arbitrary file corruption if the web service attempts to write to predictable locations.
**Prevention:** Avoid declaring global file variables in route unit implementations. Ensure any needed logging uses standard, thread-safe logging mechanisms configured with non-hardcoded, relative paths or environment-based directories, rather than `AssignFile` / `WriteLn` directly inside request handlers.
