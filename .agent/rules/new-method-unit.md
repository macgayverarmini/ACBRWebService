# Rule for New & Extended ACBr Bridge Units (`[ACBR-RTTI-CORE-PURITY]`)

This rule governs creating or extending bridge units inside `method/` (`method.acbr.<feature>.pas`) and their paired `routes/route.acbr.<feature>.pas`.

## 1. File Naming & Zero ERP Coupling
- Follow `method.acbr.<feature>.pas` and `route.acbr.<feature>.pas` (plus route constants in `resources/resource.strings.routes.pas` and registration in `ACBRWebService.lpr`).
- **NEVER** create ERP-specific units (`*.legado.pas`) or embed consumer ERP rules/tenant defaults inside `method/`. `ACBRWebService` is a generic, stack-agnostic RTTI bridge.

## 2. Canonical Pure-RTTI Unit Structure (`{$mode Delphi}` + `{$M+}`)

Every bridge MUST hydrate ACBr properties exclusively through `TJSONTools.JsonToObj` (`tools/jsonconvert.pas`) and expose real dynamic models via `TACBRModelosJSON*` (`TJSONTools.SafeObjToJson`):

```pascal
unit method.acbr.exemplo;

{$mode Delphi}
{$M+}

interface

uses
  Classes, SysUtils,
  fpjson, jsonparser, jsonconvert,
  resource.strings.global,
  resource.strings.msg,
  ACBrExemplo;

type
  TACBRBridgeExemplo = class
  private
    fcfg: string;
    facbr: TACBrExemplo;
    procedure CarregaConfig(const AllowEmpty: Boolean = True);
  public
    constructor Create(const Cfg: string);
    destructor Destroy; override;
    function Executar(const jPayload: TJSONObject): TJSONObject;
  end;

  TACBRModelosJSONExemplo = class(TACBRBridgeExemplo)
  public
    function ModelConfig: TJSONObject;
    function ModelExecutar: TJSONObject;
  end;

implementation

function TACBRModelosJSONExemplo.ModelConfig: TJSONObject;
begin
  Result := TJSONTools.SafeObjToJson(facbr);
end;

function TACBRModelosJSONExemplo.ModelExecutar: TJSONObject;
begin
  Result := TJSONTools.SafeObjToJson(facbr);
end;

procedure TACBRBridgeExemplo.CarregaConfig(const AllowEmpty: Boolean);
var
  O: TJSONObject;
begin
  if (Trim(fcfg) = '') and (not AllowEmpty) then
    raise Exception.Create(RSConfigEmptyError);
  if Trim(fcfg) <> '' then
  begin
    O := GetJSON(fcfg) as TJSONObject;
    try
      TJSONTools.JsonToObj(O, facbr);
    finally
      O.Free;
    end;
    fcfg := '';
  end;
end;

constructor TACBRBridgeExemplo.Create(const Cfg: string);
begin
  inherited Create;
  facbr := TACBrExemplo.Create(nil);
  fcfg := Cfg;
end;

destructor TACBRBridgeExemplo.Destroy;
begin
  FreeAndNil(facbr);
  inherited Destroy;
end;

function TACBRBridgeExemplo.Executar(const jPayload: TJSONObject): TJSONObject;
begin
  CarregaConfig(True);
  TJSONTools.JsonToObj(jPayload, facbr);
  facbr.ExecutarMetodoNativo;
  Result := TJSONTools.SafeObjToJson(facbr);
  Result.Add(RSStatusField, RSStatusSucesso);
end;

end.
```

## 3. Non-Negotiable Constraints
- **Mandatory RTTI:** Never bypass `TJSONTools.JsonToObj` / `ObjToJson` with manual field-by-field `jObj.Get(...)` / `jObj.Strings[...]` assignments when ACBr exposes `published`/`public` RTTI properties.
- **Pure `/modelo/*`:** Never construct synthetic/manual `TJSONObject` schemas or fake example values in `TACBRModelosJSON*` — always reflect the clean ACBr instance via `SafeObjToJson`.
- **Zero Output Patching:** Never post-process/regex XML, SPED TXT, Sintegra TXT, CNAB, or PDF strings generated by ACBr, and never swallow real ACBr/OpenSSL/SEFAZ exceptions.
- **Memory Safety:** Free all created instances in `try..finally` blocks (`FreeAndNil`).
